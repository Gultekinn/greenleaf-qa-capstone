Bug Apply Promo button overlaps Submit Order button on mobile checkout page

Severity
Major
Priority
High
Evidence
evidence/ui_bug.png

Environment

Browser
Chrome
Viewport
390x844
Operating System
Linux VM
Url
http://localhost:3000/checkout
Application
GreenLeaf Grocers (capstone_module_1)

Preconditions

User has items in the cart and is on the checkout page at mobile viewport width below 768px.

Steps to reproduce

  1. Navigate to http://localhost:3000/checkout
  2. Open Chrome DevTools and set device dimensions to 390 x 844
  3. Scroll down to the promo code and order summary section

Expected result

Apply Promo and Submit Order buttons are properly spaced and do not overlap.

Actual result

Apply Promo visually overlaps Submit Order, completely blocking the submit control.
