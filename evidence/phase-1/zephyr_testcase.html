TC-GL-01: Guest checkout happy path with valid cart items

Linked story
GL-101
Preconditions
User has items in the cart at http://localhost:3000/cart and is not signed in.
Expected result
Order is placed successfully and redirected to order confirmation page with a thank-you message.

Test steps

  1. Navigate to http://localhost:3000/checkout
  2. Fill in required shipping and billing details with valid guest information
  3. Click the Submit Order button

TC-GL-02: Checkout form validation blocks submission when required fields are missing

Linked story
GL-103
Preconditions
User has items in the cart and navigates to http://localhost:3000/checkout
Expected result
Form submission is blocked and visual validation error messages appear for the missing required fields.

Test steps

  1. Leave required shipping fields (e.g. Full Name or Address) blank
  2. Click the Submit Order button

TC-GL-03: Promo code edge case validation for expired or invalid codes

Linked story
GL-102
Preconditions
User is on the checkout page http://localhost:3000/checkout with active cart items.
Expected result
Application displays a graceful user-friendly rejection message stating the promo code is invalid or expired, without crashing.

Test steps

  1. Enter an expired or invalid promo code (e.g., EXPIRED20) into the promo code field
  2. Click the Apply Promo button
